ขั้นตอนการอัปโหลดไฟล์ขึ้น GitHub Pages (ฟรี)

คุณสามารถนำแดชบอร์ดนี้ไปเปิดใช้งานออนไลน์ได้ตลอดเวลา โดยปฏิบัติตาม 5 ขั้นตอนดังนี้:

  1. บันทึกไฟล์นี้ไว้ในเครื่อง ตั้งชื่อไฟล์ว่า index.html
  2. สร้าง Repository ใหม่บน GitHub

    เข้าสู่เว็บไซต์ github.com → กด New Repository → ตั้งชื่อ เช่น health-dashboard → เลือกเป็น **Public**

  3. อัปโหลดไฟล์ index.html

    กดปุ่ม **Add file** → **Upload files** → ลากไฟล์ index.html ลงไป แล้วกด **Commit changes**

  4. เปิดใช้งาน GitHub Pages

    ไปที่เมนู **Settings** ของ Repository → แถบซ้ายกด **Pages** → ที่หัวข้อ *Build and deployment (Source)* เลือกเป็น **Deploy from a branch** → เลือก Branch เป็น **main / root** แล้วกด **Save**

  5. รับ Link แดชบอร์ดสำหรับใช้งาน

    รอประมาณ 1-2 นาที ระบบจะสร้าง URL แดชบอร์ด เช่น https://yourname.github.io/health-dashboard/ ให้ท่านสามารถแชร์ให้ทีมงานเข้าดูได้ทันที!

คำแนะนำ: เมื่อเปิดหน้าเว็บ แดชบอร์ดจะแสดงข้อมูลตัวอย่างทันที และนักสาธารณสุขสามารถอัปโหลดไฟล์ Excel เช่น confirmed-cases-since-120465.xlsx ผ่านหน้าเว็บเพื่อแสดงผลแบบ Real-time บนบราวเซอร์ได้ทันทีโดยไม่ต้องเขียนโค้ดเพิ่ม
